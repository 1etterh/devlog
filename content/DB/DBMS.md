>[!info] DBMS
>Data Base Management System

### _DBMS_
> A database-management system(DBMS) is a collection of interrelated data and a set of programs to access those data

## [[SQL]]
> Structured Query Language
> DBMS의 데이터를 조작하기 위해 사용하는 언어
> ACID 트랜잭션 속성을 지원
