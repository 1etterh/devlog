## 질문

SSH를 통해 원격 시스템에 접속하면, 해당 시스템에 설치된 프로그램만 실행할 수 있는가?

## 답변

**맞다.** SSH로 원격 시스템에 접속하면 원격 시스템의 셸 환경에서 작업하는 것이므로, 원격 시스템에 설치된 프로그램만 실행할 수 있다.

### 핵심 원리

- SSH는 원격 시스템의 **셸 세션**을 열어주는 프로토콜이다
- 입력하는 모든 명령은 **원격 시스템의 OS**에서 실행된다
- `$PATH` 환경변수도 원격 시스템의 것을 따른다
- 로컬에 설치된 프로그램은 원격 시스템에서 인식하지 못한다

### 예시

```bash
# 내 맥북 (claude 설치됨)
$ which claude
/usr/local/bin/claude

# 사내망 서버로 SSH 접속
$ ssh user@internal-server

# 서버에서 claude 실행 시도 → 실패
server$ claude
-bash: claude: command not found
```

로컬 컴퓨터에 Claude Code가 설치되어 있어도, SSH로 접속한 사내망 서버에는 설치되어 있지 않으므로 실행할 수 없다.

### 예외 및 우회 방법

| 방법 | 설명 |
|------|------|
| **SSH 터널링/포트포워딩** | 원격 서버를 경유해 네트워크 접근만 빌리는 것. 프로그램 자체는 로컬에서 실행된다 |
| **X11 Forwarding** | 원격 시스템의 GUI 앱 화면을 로컬에 전달하여 표시하는 방법 |
| **sshfs / 원격 마운트** | 원격 파일시스템을 로컬에 마운트하여 로컬 프로그램으로 원격 파일을 편집 |
| **원격에 직접 설치** | 필요한 프로그램을 원격 서버에 설치하는 가장 직접적인 방법 |

### SSH 터널링 예시

```bash
# 로컬 포트 8080을 원격 서버 경유로 내부 서비스(192.168.1.100:80)에 연결
$ ssh -L 8080:192.168.1.100:80 user@internal-server

# 이제 로컬 브라우저에서 localhost:8080으로 내부 서비스 접근 가능
# 프로그램(브라우저)은 로컬에서 실행, 네트워크만 원격 경유
```

### 정리

SSH 접속은 본질적으로 "내 키보드 입력을 원격 서버의 셸에 전달"하는 것이다. 로컬 컴퓨터의 프로그램을 원격에서 사용할 수 있게 해주는 것이 아니라, 원격 서버의 환경 안에서만 작업하게 된다.
