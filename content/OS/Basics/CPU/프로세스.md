# 프로세스의 문맥(Context)


### 1. CPU 수행상태를 나타내는 하드웨어 문맥

1. Program Counter
2. 각종 register

### 프로세스 상태(Process State)
1. Running: CPU잡고 instruction 수행중인 상태
2. Ready: 다른 조건을 모두 만족하고 CPU를 기다리는 상태(in memory)
3. Blocked(wait, sleep)
	1. CPU를 주어도 당장 instruction을 수행할 수 없는 상태
	2. Process 자신이 요청한 event(예: IO)가 만족되지 않아 기다리는 상태
	3. ex. 디스크에서 file을 읽어와야 하는 경우
4. New: 프로세스가 생성중인 상태
5. Terminated: 수행(execution)이 끝난 상태
