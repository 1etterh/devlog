NMS와 장비가 주고받는 통신. [[cs/network/nms/data/topology/index|토폴로지]]와 [[cs/network/nms/data/monitoring/index|감시]]가 같은 경로를 쓰므로 한곳에 정리한다. 수집 방법 자체는 [[cs/network/nms/collection/index|수집]].

## SNMP

| 버전 | 인증 | 암호화 | 문제 |
|---|---|---|---|
| v1 / v2c | community 문자열(비밀번호 역할) | 없음 | community가 **평문**으로 오간다. 도청하면 그대로 쓸 수 있다 |
| v3 (USM) | 사용자 + HMAC-SHA | AES | 보안 수준을 고른다: `noAuthNoPriv` / `authNoPriv` / **`authPriv`**(인증 + 암호화) |

- **v3 `authPriv`**를 쓰는 게 기본 권고다. 옛 장비 때문에 v2c를 써야 하면 관리망 분리 + ACL로 보완한다.
- 기본 community `public`(읽기)·`private`(쓰기)는 반드시 바꾼다. 장비 출고 상태 그대로인 경우가 많다.
- **쓰기(SET) 권한을 주지 않는다.** 수집에는 읽기만 필요하다. 쓰기 community가 새면 설정을 바꿀 수 있다.
- **VACM**으로 읽을 수 있는 MIB 범위를 좁힌다(예: 수집에 필요한 system·IF-MIB·LLDP-MIB만).
- 장비의 SNMP는 NMS 주소에서만 받는다. 인터넷에 열린 SNMP는 **반사 증폭 공격**(작은 GetBulk 요청 → 큰 응답을 위조된 피해자 주소로)에 악용된다.

## trap · syslog

| 항목 | 문제 | 대응 |
|---|---|---|
| v1 / v2c trap | UDP라 보낸 주소를 위조할 수 있다. 가짜 `linkDown`으로 거짓 경보를 만든다 | SNMPv3 trap(인증), 등록된 장비 주소만 받기, 폴링으로 교차 확인 |
| syslog (UDP 514) | 인증·암호화 없음. 위조·도청·유실 | syslog over TLS(RFC 5425, TCP 6514), 관리망 안에서만 |
| 받는 쪽 | 아무 주소에서나 받으면 폭주에 약하다 | 방화벽으로 장비 대역만 허용, 초당 수신 제한([[cs/network/nms/security/monitoring#경보-폭주|경보 폭주]]) |

trap·syslog로 받은 내용은 **증거가 아니라 신호**로 다룬다. 중요한 상태는 폴링으로 다시 확인한다.

## SSH · 텔레메트리

| 프로토콜 | 주의 |
|---|---|
| SSH (CLI 수집, 설정 백업) | Telnet 금지. **호스트 키 확인**(처음 받은 키를 저장하고 바뀌면 경고) — 끄면 중간자 공격에 열린다. 비밀번호보다 키 인증 |
| gNMI · NETCONF | TLS / SSH 위에서 돈다. 인증서 검증을 끄지 않는다. 가능하면 상호 인증(mTLS) |

## 인증 정보 보관

NMS는 모든 장비의 community·SNMPv3 비밀번호·SSH 키를 가진다. 가장 값비싼 표적이다.

- 인증 정보는 노드 데이터에 넣지 않는다. **별도 보관소**(비밀 관리 도구, 암호화된 저장소)에 두고 노드는 **참조 id**만 가진다([[cs/network/nms/extension#관리-접속-정보access|범위 밖 단위 › 관리 접속 정보]]).
- 저장할 때 암호화하고, 화면·API·로그에 값을 내보내지 않는다(마스킹).
- 장비마다 다른 인증 정보가 이상적이다. 하나를 전 장비에 쓰면 한 번 새면 전부 열린다.
- 인증 정보를 쓰는 건 수집 프로세스뿐이다. 화면 사용자는 값을 보지 못하고 "어떤 인증 정보를 쓸지" 고르기만 한다.

## 발견(스캔)

대역 스캔·이웃 따라가기(LLDP 크롤)로 장비를 찾는 과정도 보안 이슈가 있다.

- **허락된 범위만** 스캔한다. 스캔 대역을 명시적으로 등록하게 하고, 그 밖은 이웃 정보에 나와도 따라가지 않는다.
- 스캔은 침입 탐지(IDS)에 공격으로 보일 수 있다. 보안 담당과 NMS 주소를 공유한다.
- 발견한 장비는 바로 수집하지 않고 **승인 대기**를 거친다. 공격자가 심은 장비가 자동으로 맵에 들어오는 걸 막는다.
- 여러 인증 정보를 돌려 가며 시도하면 장비 쪽 로그인 실패 경보·계정 잠금을 일으킨다. 시도 횟수를 제한한다.
