# 유연성 (cf. 호환성)
> 여러 곳에 적용될 수 있는 유연한 객체를 의미하며, 재사용성이 높아질 수 있게 한다는 의미이다. <br/>
> 상위 타입으로 올라갈수록 공통적인 속성만 모여있다.

- [[Interface|인터페이스]] - 완전한 추상화를 제공하는 도구

- [[Polymorphism|다형성]] - 추상화된 타입을 활용한 유연한 코드
