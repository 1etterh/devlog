> 유지보수성을 증가시키기 위해 필드의 직접 접근을 제한하고<br/> public method를 이용해서 간접적으로(우회해서) 접근할 수 있도록 만든 기술 <br/> 
> 클래스 작성 시 특별한 목적이 있지 않다면 캡슐화를 사용하는 것을 기본 원칙으로 하고 있다.


#### [[Information Hiding|정보은닉]]의 종류

2. 타입 은닉
3. 필드 은닉(Encapsulation)
