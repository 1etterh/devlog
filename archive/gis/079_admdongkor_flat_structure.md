**Q**: 그러면 admdongkor 원본은 전부 다 한 파일에 flat하게 들어가 있는 거지?

**A**:

네, 맞아요. 원본은 파일 하나(`HangJeongDong_ver20261001.geojson`, 약 35MB)에 **읍·면·동 3,559개가 단계 구분 없이 한 배열에** 나란히 들어 있어요.

```
features: [
  사직동   (sido 11, sgg 11110),
  삼청동   (sido 11, sgg 11110),
  ...
  양평읍   (sido 41, sgg 41830),
  ...                          ← 3,559개가 그냥 나열
]
```

- **시도·시군구 지역은 따로 없어요.** 서울특별시나 종로구 같은 경계 도형은 원본에 없고, 각 읍·면·동 feature가 자기가 속한 시도·시군구를 **속성으로만** 갖고 있어요(`sido`, `sidonm`, `sgg`, `sggnm`).
- 그래서 변환할 때 이렇게 만들었어요.
  - **시도·시군구 경계**: 같은 `sido`나 `sgg`를 가진 읍·면·동을 하나로 합쳐서(dissolve) 만들었어요.
  - **단계별 파일**: 그 속성 값으로 나눠서(split) 부모 경로를 이름으로 한 파일(`KR.json`, `KR.41.json`, `KR.41.830.json` …)로 만들었어요. 한 폴더에 평평하게 둬요(처음엔 `KR/{시도}/{시군구}/index.json` 폴더 구조였어요).

| | 원본 | 변환 후 |
|---|---|---|
| 파일 | 1개 | 273개 (시도 1 + 시군구 16 + 읍면동 256) |
| 단계 | 읍·면·동만 있고 상위 지역은 속성으로만 | 시도, 시군구, 읍면동 경계가 각각 있음 |
| 상위 지역을 아는 방법 | `sido`, `sgg` 속성 | 파일 이름(= 부모 경로)과 `idPath` |
