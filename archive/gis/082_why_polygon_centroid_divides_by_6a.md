먼저 짚을 점: 코드에서 나누는 값은 `3 * area`가 아니라 `3 * area2`다. `area2`는 넓이의 **2배**이므로 실제로는 **넓이의 6배(6A)**로 나눈다. 이건 다각형 무게중심 공식 그대로다.

$$C_x = \frac{1}{6A}\sum (x_i + x_{i+1})(x_i y_{i+1} - x_{i+1} y_i)$$

```ts
let area2 = 0; // 넓이 × 2
for (...) {
  const cross = x0 * y1 - x1 * y0;
  area2 += cross;
  cx += (x0 + x1) * cross;
  cy += (y0 + y1) * cross;
}
center = [cx / (3 * area2), cy / (3 * area2)];
```

### 왜 6A인가: 원점에서 삼각형으로 쪼개기

신발끈 공식은 다각형을 **원점 O와 변 하나씩으로 만든 삼각형** (O, Pᵢ, Pᵢ₊₁)들로 쪼개서 계산하는 방식이다.

| 항목 | 삼각형 하나 (O, Pᵢ, Pᵢ₊₁) | 코드 |
|---|---|---|
| 부호 있는 넓이 | `cross / 2` | `cross = x0*y1 - x1*y0` |
| 무게중심 | `(0 + x0 + x1) / 3` (세 꼭짓점 평균, O는 0) | `(x0 + x1)` |

전체 무게중심은 **각 삼각형 무게중심을 넓이로 가중평균**한 값이다.

$$C_x = \frac{\sum \frac{cross}{2}\cdot\frac{x_0+x_1}{3}}{A} = \frac{\sum (x_0+x_1)\cdot cross}{6A}$$

- **2**: 삼각형 넓이가 외적의 절반이라서 생긴다.
- **3**: 삼각형 무게중심이 세 꼭짓점의 평균이라서 생긴다.
- 2 × 3 = 6이 분모로 묶여 나온다.

코드는 `/2`와 `/3`을 루프마다 하지 않고 합계(`cx`)를 다 구한 뒤 한 번에 나눈다. `area2 = 2A`이니 `3 * area2 = 6A`가 된다.

### 부호는 신경 안 써도 되는 이유
- 원점이 다각형 밖에 있으면 일부 삼각형은 음수 넓이가 된다. 이 음수가 다각형 밖으로 튀어나온 부분을 정확히 빼 준다.
- 고리가 시계 방향이면 `cx`와 `area2`의 부호가 **같이** 뒤집혀서 나눗셈 결과는 그대로다. 그래서 `center`에는 `Math.abs`가 없고, 넓이(`area`)에만 붙어 있다.
