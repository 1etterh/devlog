**Q**: 벡터 DB에서 "개"와 "강아지"가 비슷하다는 사실은 어떻게 알게 되는가? 사람이 직접 입력하는가?

**A**:
- 사람이 단어 쌍을 입력하지 않음. **임베딩 모델이 대량의 텍스트에서 스스로 학습**함
- 근거는 **분포 가설**: 비슷한 문맥에 등장하는 단어는 의미도 비슷하다 ("개/강아지가 짖었다", "개/강아지 산책")
- Word2Vec은 주변 단어를 예측하도록 학습되며, 문맥이 같은 단어는 결과적으로 비슷한 벡터를 갖게 됨
- 최신 문장 임베딩은 **대조 학습**: 같은 뜻의 문장 쌍(질문-답, 제목-본문, 번역 쌍 등)은 가깝게, 무관한 문장은 멀게 만들도록 학습
- **벡터 DB는 의미를 모름**. 코사인 유사도 같은 거리 공식만 계산하고, "무엇이 가까운가"는 임베딩 모델이 결정

사람의 개입은 학습 데이터(문장 쌍, 라벨, 클릭 로그)를 고르는 간접적인 수준에 그친다. 그래서 도메인 용어가 잘 안 맞으면 모델을 바꾸거나 파인튜닝한다.
